# 🖥️ 1.1 Computer Hardware Components
> **Tag:** #it-skills #hardware #basics #module-1

## 📌 Why Hardware Knowledge Matters in Security
As a cybersecurity specialist, you protect software and data, but everything runs on physical hardware. Knowing hardware helps you understand physical security, how memory injection attacks work, and why GPUs are used to crack passwords.

---

## 🏗️ Core Hardware Components (The Restaurant Analogy)
Think of a computer like a busy restaurant kitchen to easily understand how the components work together:

| Component | Kitchen Analogy | What it Does in a Computer | Security Relevance |
|---|---|---|---|
| **CPU (Central Processing Unit)** | **The Head Chef** | Executes instructions, performs calculations, and coordinates other components. | Process security, kernel rings, and instruction execution. |
| **RAM (Random Access Memory)** | **The Prep Table** | Super-fast, **volatile** (temporary) memory holding active data currently in use. Cleared when power is off. | Volatile data forensics. Contains passwords, decryption keys, and active network connections. |
| **SSD / HDD (Storage)** | **The Pantry / Freezer** | **Non-volatile** (permanent) storage holding your OS, apps, and files. Stays when power is off. | Data recovery, secure deletion, and disk encryption (e.g., BitLocker). |
| **GPU (Graphics Processing Unit)** | **The Vegetable Chopper** | Handles massive parallel tasks. Perfect for graphics, AI, and neural networks. | **Password Cracking**: GPUs can guess billions of hashes per second compared to CPUs. |
| **Motherboard** | **The Kitchen Floor** | The main printed circuit board connecting all components. | Physical tampering and hardware backdoors (like spy chips). |
| **NIC (Network Interface Card)** | **The Delivery Door** | The hardware component connecting the PC to a network (via Ethernet or Wi-Fi). | Holds your permanent physical **MAC Address**. |

---

## 🔬 A Closer Look: Memory vs. Storage

A common beginner mistake is confusing RAM and Storage. Here is the difference:

* **RAM (Memory)**: 
  * *Speed*: Extremely fast.
  * *Volatilization*: If the computer restarts, RAM contents are wiped.
  * *Security Hack*: If an attacker gains access to a running machine, they can dump the RAM to find passwords in plain text!
* **SSD/HDD (Storage)**:
  * *Speed*: Slower than RAM.
  * *Volatilization*: Data persists through reboots.
  * *Security Hack*: Deleting a file just hides it; the actual data remains on the disk until overwritten. Forensic tools can recover deleted files easily unless securely wiped!

## 🛠️ Hands-on Exercise: Check Your Own Hardware!

Let's find your hardware specifications without opening the computer case.

### For Windows:
1. Press `Ctrl + Shift + Esc` to open **Task Manager**.
2. Click on the **Performance** tab on the left.
3. Click through **CPU**, **Memory (RAM)**, **Disk (SSD/HDD)**, and **GPU** to see their names, speeds, and capacities.

### Using Command Prompt/Powershell:
Run this command in Powershell to get your CPU model:
```powershell
Get-CimInstance Win32_Processor | Select-Object Name, MaxClockSpeed, NumberOfCores
```
