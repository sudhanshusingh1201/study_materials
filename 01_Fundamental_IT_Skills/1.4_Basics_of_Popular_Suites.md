# 📂 1.4 Basics of Popular Suites
> **Tag:** #it-skills #productivity #cloud-suites #module-1

## 📌 Why Productivity Suites Matter in Security
Corporate offices run on productivity suites: **Microsoft 365 (Office)**, **Google Workspace**, and **Apple iCloud**. Because these suites handle sensitive emails, contracts, financials, and files, they are primary targets for hackers.

---

## 🗃️ The Three Major Productivity Suites

### 1. Microsoft 365
* **Key Apps**: Word, Excel, PowerPoint, Outlook, Teams, OneDrive.
* **Storage**: **OneDrive** (files) and **SharePoint** (team collaboration).
* **Corporate Standard**: Most enterprises use Microsoft 365 integrated with Azure Active Directory.

### 2. Google Workspace
* **Key Apps**: Docs, Sheets, Slides, Gmail, Meet, Google Drive.
* **Storage**: **Google Drive**.
* **Cloud-First**: Relies entirely on the browser, meaning fewer local file execution risks.

### 3. Apple iCloud
* **Key Apps**: Pages, Numbers, Keynote, iCloud Mail, iCloud Drive.
* **Storage**: **iCloud Drive**.
* **Consumer-First**: Popular among consumers and macOS-dominant creative environments.

## ⚠️ Security Risks in Productivity Suites

Productivity suites are vulnerable to attacks that exploit human behavior:

### 1. Macro Malware (The Classic Office Threat)
* **What it is**: Microsoft Office documents can run custom scripts called **Macros** (written in Visual Basic for Applications - VBA) to automate tasks.
* **The Attack**: Attackers send a phishing email with a Word document attachment (e.g., `Invoice.docm`). When opened, the document asks the user to "Enable Content" (which turns on macros). Once enabled, the macro runs malicious code that downloads and installs malware on the user's PC.
* **Defense**: Microsoft now blocks macros by default for files downloaded from the internet. Never click "Enable Content" on suspicious documents!

### 2. Malicious File Sharing / Public Links
* **What it is**: Sharing files via a link is easy, but dangerous if not managed.
* **The Attack**: An employee shares a spreadsheet containing customer passwords using the setting *"Anyone with the link can edit."* If that link is forwarded, leaked, or scraped by search engines, the data is compromised.
* **Defense**: Always share files with *specific people* using their email addresses, not open public links.

### 3. Collaboration Phishing
* **What it is**: Attackers use the comment features in Google Docs or Microsoft Word to tag targets.
* **The Attack**: You receive a legitimate email from Google Docs saying *"User X mentioned you in a comment."* The comment contains a link to a fake login page. Because the email came from a real Google server, email filters don't block it.
* **Defense**: Verify the user who mentioned you and never input passwords on landing pages linked from comments.
