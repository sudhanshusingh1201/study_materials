# Phase 1: Computer & Operating System Basics (Month 1)
Before securing systems, you must know how they work.

*   **Core Concepts to Learn:**
    *   How hardware works (CPU, RAM, Hard Drive, Motherboard).
    *   **Windows Internals:** Registry, Services, Processes, Event Viewer, Active Directory basics.
    *   **Linux Internals:** File system structure, Kernel vs User space, Package management (apt, yum).
*   **Actionable Tasks:**
    *   Install VMware or VirtualBox on your main computer.
    *   Set up a Windows VM and a Linux VM (Kali Linux or Ubuntu). Experiment with system settings, services, and task manager equivalents.
*   **Free Resources:**
    *   [Computer Science 101 - Crash Course](https://www.youtube.com/playlist?list=PL8dPuuaLjXtNlUrzyH5r6jN9ulIgZBpdo) (YouTube)
    *   [Windows Internals for Beginners](https://tryhackme.com/module/windows-fundamentals) (TryHackMe - Free Modules)
