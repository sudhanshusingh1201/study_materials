# Phase 3: Linux Command Line & Scripting (Month 3)
Linux is the OS of servers, hackers, and security tools. Scripting helps you automate tasks.

*   **Core Concepts to Learn:**
    *   File navigation, editing files (`nano`, `vim`), finding files (`find`, `locate`).
    *   Text manipulation tools: `grep`, `awk`, `sed`, `cut`.
    *   Linux User Groups & Permissions (`chmod`, `chown`, SUID/SGID).
    *   **Bash Scripting:** Automating repetitive commands.
    *   **Python Basics:** Variables, loops, functions, socket programming.
*   **Actionable Tasks:**
    *   Play **OverTheWire: Bandit** (Levels 0 to 20).
    *   Write a simple Bash script that pings a range of IP addresses to find active hosts.
    *   Write a basic port scanner in Python.
*   **Free Resources:**
    *   [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) (Best gamified Linux command training)
    *   [Python for Everybody - Dr. Chuck](https://www.py4e.com/) (Best beginner coding resource)
