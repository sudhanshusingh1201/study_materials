# Phase 4: Cybersecurity Fundamentals (Month 4-5)
Learn the core theories and concepts of security.

*   **Core Concepts to Learn:**
    *   **Security Pillars:** Confidentiality, Integrity, Availability (CIA Triad).
    *   **Cryptography:** Symmetric vs Asymmetric encryption, Hashing (MD5, SHA-256), Encoding (Base64, Hex).
    *   **Common Threats:** Phishing, Malware types (Ransomware, Trojans, Rootkits), Social Engineering.
    *   **Identity Access Management (IAM):** Authentication vs Authorization, Multi-Factor Authentication (MFA).
*   **Actionable Tasks:**
    *   Study for the CompTIA Security+ concepts (even if you don't take the exam immediately, the content is essential).
*   **Free Resources:**
    *   [Professor Messer CompTIA Security+ Course](https://www.youtube.com/playlist?list=PLG49S3nxzAnkL2g1jiSnyYdH-yIPKK79K) (Standard entry-level security curriculum)
    *   [TryHackMe - Intro to Cyber Security Pathway](https://tryhackme.com/path/outline/introtosecurity) (Free hands-on learning)
