# 📡 3. Network Transceivers (GBIC, SFP, SFP+, QSFP, SR/LR)

Transceiver = **Trans**mitter + Re**ceiver**. Ye ek small hot-pluggable hardware module hai jise switches/routers ke empty slots me insert kiya jata hai taaki switches alag-alag types ke fiber ya copper cables se connect ho sakein.

### 🗂️ Major Transceiver Types:
* **GBIC:** Purane bade size ke modules (1 Gbps).
* **SFP (Mini-GBIC):** Compact size ports, runs at 1 Gbps.
* **SFP+:** Same size as SFP, runs up to 10 Gbps.
* **QSFP (Quad SFP):** Uses 4 channels. QSFP+ = 40 Gbps (4x10G), QSFP28 = 100 Gbps (4x25G), QSFP-DD = Up to 400G/800G.

### 🎯 Distance Classifications (SR vs. LR vs. ER/ZR):
* **SR (Short Range):** Multi-mode fiber (MMF) ke liye, supports up to ~300 meters. (Inside data centers).
* **LR (Long Range):** Single-mode fiber (SMF) ke liye, supports up to 10 kilometers. (Campus backbones).
* **ER/ZR (Extended Range):** Single-mode fiber, supports up to 40-80 km. (Telecom networks).
