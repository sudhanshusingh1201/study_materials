# 🔒 9. Private, Public, Static & Dynamic IPs (NAT, DHCP)

* **Private IP:** LAN me free use ke liye range. Internet par direct routable nahi hoti. (e.g., `192.168.X.X`).
* **Public IP:** Globally unique paid IP, jo internet par access ke liye use hoti hai.
* **NAT (Network Address Translation):** Router local private IPs ko single/multiple public IPs me translate karta hai taaki internet access ho sake.
* **Static IP:** Permanent manual IP lock (servers/printers ke liye).
* **Dynamic IP:** DHCP server dwara automatically assigned temporary dynamic IP address.
