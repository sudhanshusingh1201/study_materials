# 🖥️ 13. Network Devices & Switching Concepts (Domains, Asymmetric, ASIC)

### 🧩 Collision vs. Broadcast Domains
* **Collision Domain:** Traffic collision range. Switches isolate collisions on every single port. Hubs share 1 single collision domain.
* **Broadcast Domain:** Broadcast packet range. Switches/Hubs default to 1 broadcast domain. Routers drop broadcasts, so each router interface defines a separate broadcast domain.
