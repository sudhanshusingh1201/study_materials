📝 1. Lab Overview & Topology
-----------------------------------------------------------------
Is lab mein hum Cisco Packet Tracer ka basic user interface (UI) seekhenge aur ek simple local area network (LAN) topology banakar connectivity test karenge.

Topology Components:
* 1x Cisco Switch (Model: 2960)
* 3x End Devices (PCs: PC0, PC1, PC2)
* 3x Copper Straight-Through Cables

Topology Structure (Visual representation):

       [PC0: 192.168.1.1]
              | (Fa0 -> Fa0/1)
              |
      [2960 Central Switch]
        /           \
       /             \ (Fa0/3 -> Fa0)
      / (Fa0/2 -> Fa0) \
     /                  \
[PC1: 192.168.1.2]    [PC2: 192.168.1.3]

Illustration Reference: ../images/day_1_lab_topology.jpg

🛠️ 2. Step-by-Step Lab Instructions
-----------------------------------------------------------------

Step 1: Place the Devices (Devices set up karein)
* Packet Tracer open karein.
* Left-bottom panel se "Network Devices" -> "Switches" select karein.
* "2960" Switch par click karke use logic board (white space) par drag & drop karein.
* Left-bottom panel se "End Devices" select karein.
* "PC" select karke 3 PCs (PC0, PC1, PC2) workspace par lagayein.

Step 2: Connect the Cables (Physical connection karein)
* Left-bottom se "Connections" (Orange lightning bolt icon) select karein.
* "Copper Straight-Through Cable" (solid black line) select karein.
* PC0 par click karke "FastEthernet0" port select karein.
* Cable ko Switch par drag karke click karein aur use "FastEthernet0/1" port se connect karein.
* Same steps follow karke:
  - PC1 (FastEthernet0) ko Switch (FastEthernet0/2) se connect karein.
  - PC2 (FastEthernet0) ko Switch (FastEthernet0/3) se connect karein.

Step 3: Configure IP Addresses (Logical IP Settings)
* PC0 par double-click karein -> Desktop tab -> "IP Configuration" option open karein.
* IPv4 Address set karein: 192.168.1.1
* Subnet Mask box par click karein, ye automatically load hoga: 255.255.255.0
* Screen close karein.
* Same tarike se:
  - PC1 ko IP Address: 192.168.1.2 assign karein.
  - PC2 ko IP Address: 192.168.1.3 assign karein.
  * (Sabhi ka subnet mask same 255.255.255.0 rahega).

Step 4: Verify Connectivity (Ping Check)
* PC0 par double-click karein -> Desktop tab -> "Command Prompt" select karein.
* Pehle verify karein ki local IP settings load hui hain ya nahi. Command likhein:
  > ipconfig
* PC1 ko ping karne ke liye command run karein:
  > ping 192.168.1.2
* PC2 ko ping karne ke liye command run karein:
  > ping 192.168.1.3

Expected Success Output:
"Reply from 192.168.1.2: bytes=32 time<1ms TTL=128" (4 packets sent, 4 packets received, 0% loss).

-----------------------------------------------------------------
💡 3. Key Concepts & Troubleshooting
-----------------------------------------------------------------
* Red Link Light: Link down hai. Interface shutdown hai ya physical cabling connection loose/wrong hai.
* Amber/Orange Link Light: Link operational transition mein hai. Cisco switches par loop prevention (Spanning Tree Protocol) check chalu hota hai. 30-50 seconds mein ye automatically green ho jayega.
* Green Link Light: Link up/up operational state mein hai aur data forward kar sakta hai.

📝 4. CCNA Day 01 Lab Practice Questions (Quiz)
=================================================================

Q1: PC se Switch ko connect karne ke liye kis type ki copper cable ka use kiya jata hai?
Answer: Copper Straight-Through Cable (Kyunki ye different layers ke heterogeneous devices hain).

Q2: Packet Tracer panel par FastEthernet ports ke connectivity indicators direct wire lagate hi temporary orange kyu show karte hain?
Answer: STP (Spanning Tree Protocol) active check run ho raha hota hai taaki local loop prevent kiya ja sake.

Q3: PC ko local network par IP parameters check karne ke liye command prompt par kaun si utility run karni padti hai?
Answer: ipconfig command.

Q4: Router to Router direct connection ke liye hume straight-through cable use karni chahiye ya crossover cable?
Answer: Crossover Cable (Same layer endpoints).

Q5: Do local devices ke beech configuration settings and ping logic check karne ke liye default ICMP protocol request/reply kaun use karta hai?
Answer: ping command utility.

Q6: Packet Tracer ke kis workspace mein hum geographic mapping (building floor plan, wiring closet) load karte hain?
Answer: Physical Workspace.

Q7: Agar hum standard Crossover cable se switch-to-switch connect karein aur switch par Auto-MDIX enable ho, toh kya network chalega?
Answer: Haan, Auto-MDIX automatically logical lines cross karke session establish kar dega.

Q8: Subnet Mask "255.255.255.0" kis IP Address Class ka standard default mask hai?
Answer: Class C IP Addressing.

Q9: FastEthernet0/1 interface hardware level par maximum kitni data transfer rate speed support karta hai?
Answer: 100 Mbps (Megabits per second).

Q10: Packet Tracer software tool ka main benefit (use-case) kya hai?
Answer: Physical hardware hardware ke bina complex network topologies design, test, aur troubleshoot karna in a simulated environment.
