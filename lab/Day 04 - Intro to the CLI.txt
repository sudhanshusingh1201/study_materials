! =================================================================
! 🎓 CCNA Day 04: Introduction to the CLI - Lab Configuration Script
! =================================================================
! Instructions: 
! 1. Open Cisco Packet Tracer.
! 2. Click on Switch S1 -> go to CLI tab.
! 3. Copy this entire script and paste it directly into the console.
! 4. The commands will execute sequentially.
! =================================================================

enable
configure terminal

! -----------------------------------------------------------------
! Task 1: Switch Hostname badalkar 'S1' karein
! -----------------------------------------------------------------
hostname S1

! -----------------------------------------------------------------
! Task 2: Enable Password (cisco) & Enable Secret (cisco123) configure karein
! -----------------------------------------------------------------
enable password cisco
enable secret cisco123

! -----------------------------------------------------------------
! Task 3: Console Line Port access secure karein
! -----------------------------------------------------------------
line console 0
password cisco
login
exit

! -----------------------------------------------------------------
! Task 4: VTY Lines (0 to 15) remote access secure karein
! -----------------------------------------------------------------
line vty 0 15
password cisco
login
exit

! -----------------------------------------------------------------
! Task 5: Banner MOTD warning configure karein
! -----------------------------------------------------------------
banner motd # WARNING: Unauthorized Access is Prohibited! #
exit

! -----------------------------------------------------------------
! Task 6: Active configuration RAM se NVRAM (save) mein copy karein
! -----------------------------------------------------------------
copy running-config startup-config
! Press [Enter] when prompted: Destination filename [startup-config]?

! -----------------------------------------------------------------
! Verification Commands (Optional: Copy-paste to verify)
! -----------------------------------------------------------------
! show running-config
! show startup-config
! exit
